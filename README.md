# UK house price prediction model

This revised project contains five consistent Jupyter notebooks:

1. `data_understanding_etl.ipynb` — detailed data understanding and basic ETL.
2. `Data_analysis_eda.ipynb` — exploratory data analysis.
3. `feature_engineering.ipynb` — feature engineering and PCA study.
4. `model_training.ipynb` — model training, cross-validation, and hyperparameter tuning.
5. `final_pipeline.ipynb` — final pipeline, saved model, and Kaggle submission.
