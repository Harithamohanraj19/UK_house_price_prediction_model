# Ames Housing PCA Portfolio Project

This revised project contains five consistent Jupyter notebooks:

1. `01_data_understanding_etl.ipynb` — detailed data understanding and basic ETL.
2. `02_eda.ipynb` — exploratory data analysis.
3. `03_feature_engineering_pca.ipynb` — feature engineering and PCA study.
4. `04_model_training_pca.ipynb` — model training, cross-validation, and hyperparameter tuning.
5. `05_final_pipeline_submission.ipynb` — final pipeline, saved model, and Kaggle submission.

Run the notebooks in order from the `notebooks/` folder.
